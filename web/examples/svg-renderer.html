Everything below is vector — one <path> per triangle in a live <svg> element, not a canvas. Zoom the page in and the edges stay sharp. There is no WebGL or WebGPU context on this page at all: the renderer runs on the CPU in wasm, so it works where an adapter is unavailable. Curved surfaces are emitted as real Béziers, which is why the sphere's outline is a circle rather than the polygon its geometry actually is — turn curves off to see the difference.

Turning it on

import THREE, { initThreers, SVGRenderer } from '../threejs-shim.js';
await initThreers();

const renderer = new SVGRenderer();
renderer.setSize(800, 600);
document.body.appendChild(renderer.domElement);   // this is what enables it

renderer.render(scene, camera);                   // draws into domElement

// or, with no DOM at all — the same markup as a string:
const markup = renderer.renderToString(scene, camera);
